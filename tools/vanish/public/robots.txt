# Vanish is part of justintmccain.com. It is meant to be shared, not found.
#
# This file exists because this app answers on TWO public origins: the
# portfolio's own domain at /vanish, and its <site>.netlify.app deployment
# directly. Before this there was no robots.txt on the Netlify origin at all,
# which meant the portfolio could be perfectly suppressed while an identical
# copy stayed fully crawlable one hostname over.
#
# Crawling is ALLOWED on purpose. Every response carries
# `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet` from next.config.ts,
# and a crawler that is blocked here can never read that — it would be free to
# list the URL from an external link instead, with no title and no description
# and no way to correct it. Allowing the fetch is what makes the noindex bite.
#
# The same reasoning, at more length, is in the portfolio's site/robots.txt.
