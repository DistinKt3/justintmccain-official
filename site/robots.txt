# ============================================================================
# This site is meant to be SHARED, not FOUND.
# ============================================================================
#
# It should reach people it was sent to — from a resume, or a LinkedIn message.
# It should not be what someone lands on while searching an employer's name and
# "privacy".
#
# WHY THIS FILE DOES NOT SAY `Disallow: /`
#
# That is the obvious move and it is the wrong one, for two separate reasons.
#
# 1. Disallow blocks CRAWLING, not INDEXING. A crawler forbidden from fetching
#    the page can never see the `noindex` inside it. If the URL is linked from
#    anywhere else, search engines may still list it — as a bare URL with no
#    title and no description, which is both ugly and unfixable, because the
#    instruction that would fix it sits in a page they are not allowed to read.
#    Allowing the crawl is what makes the noindex effective.
#
# 2. LinkedIn's preview bot honours robots.txt. `Disallow: /` would very likely
#    turn every shared link into a bare URL with no card, no title and no image
#    — breaking the one distribution path this site actually has.
#
# So: crawling is allowed, and every response carries `noindex, nofollow,
# noarchive, nosnippet` in both a meta tag and an X-Robots-Tag header. The
# header matters because meta tags only exist in HTML — it is what covers the
# OG image, the film and the fonts.
#
# The groups below are crawlers that are not search engines and will never
# render a preview for anyone. They gain nothing from reading a noindex, so they
# are told not to come. Named explicitly because robots.txt has no wildcard for
# "AI crawlers", and an unmatched bot falls through to the permissive group.

# --- Search and preview crawlers -------------------------------------------
# Allowed to crawl SO THAT they can read the noindex and honour it.

Disallow:
